# NoxxyBot 🚀

Next-generation Roblox Whitelist and Script Protection system combined with a powerful Discord bot and modern GitHub Pages frontend.

## 🌟 Features
- **Secure Script Protection**: Prevent script leaks and bypasses using robust API endpoints and HWID locking.
- **Discord Integration**: Seamless user verification and whitelist management through Discord OAuth2 and bot commands.
- **Modern UI**: Styled with Tailwind CSS, featuring a dark cyberpunk/gaming aesthetic inspired by top-tier script hubs.
- **Multi-language Support**: Fully configured for English and Vietnamese interfaces.

## 📂 Project Structure
- `index.html` - English Landing Page
- `verify.html` - Key Verification System
- `dashboard.html` - User & Admin Management Dashboard
- `README.md` - Project Documentation
